Catatan aktivitas harian

Cukup tulis poin-poin singkat, satu kegiatan per baris. Kalimat formalnya disusun oleh generator.

Ketuk contoh di atas untuk menambahkannya, lalu sesuaikan dengan kegiatan aslimu.

Narasi untuk Monev MagangHub

Narasi dibuat dari template dan variasi kalimat berdasarkan aktivitas yang kamu isi (bukan AI). Teks bisa diedit langsung. Baca ulang dan sesuaikan agar sesuai kejadian sebenarnya sebelum dikirim.

Dukungan perangkat ini

    Penting: batas pengingat

    Pengingat ini dijalankan JavaScript di halaman web, sehingga hanya berfungsi selama halaman/tab ini masih terbuka (boleh di latar belakang, tetapi browser seluler dapat menidurkan tab). Jika halaman ditutup penuh, pengingat tidak dijamin berbunyi.

    Notifikasi yang tetap muncul saat website ditutup membutuhkan Web Push dari server (VAPID), yang tidak tersedia pada hosting statis GitHub Pages. Langkah tambahannya dijelaskan di README. Sebagai cadangan, pasang juga alarm bawaan HP pada jam yang sama.

    Riwayat aktivitas

    Data tersimpan di LocalStorage browser ini saja. Ekspor cadangan secara berkala, terutama sebelum membersihkan data browser.
